## Changes from My Original Assumptions

- Notes limit increased from 100 to 250 words.
- Button label changed from "Reset saved data" to "Clear".
- Recipe books are based on categories and tags, not preset books.
- Book creation supports automatic category-based inclusion and manual additions.
- Search and category filtering must work together.
- Approximately six built-in sample recipes will be included.
- Built-in sample recipes can be favorited but cannot be deleted.
- "My Recipes" starts empty.
