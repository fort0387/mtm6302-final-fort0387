## Project Description

Pocket Recipes is a recipe management application designed for people who enjoy cooking or want to learn how to cook. Users can save recipes, organize them into recipe books, mark their favourite recipes, and view recipe details.

## Main Features

- Add new recipes with titles, images, ingredients, preparation times, and instructions.
- Delete recipes with a confirmation message.
- Mark recipes as favourites and remove them from favourites.
- Create recipe books to organize recipes.
- Open and view detailed recipe information.
- Search recipes by name and browse by category.
- Save application data using Local Storage.

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
